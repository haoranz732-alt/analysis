银行定期存款营销响应预测与风控分析
项目简介
本项目基于银行 75 万条真实电话营销数据，围绕客户定期存款订阅行为展开全流程数据分析与建模。
核心目标：
挖掘影响客户转化的关键因素与风险特征
构建高潜客户识别预测模型
输出可落地的精准营销策略与风控建议
业务定位：营销效率提升 + 客户资质初筛（适配风控 / 数分 / 运营岗方向）
一、项目背景
银行传统电话营销存在触达盲目、资源浪费、转化率偏低等问题。
本项目通过数据分析识别高价值客群、关键影响因子、最优营销时机，并结合贷款、负债、历史行为等特征进行客户风险 / 资质判断，实现 “精准营销 + 轻量风控” 双输出。
二、数据概况
数据规模：750,000 条客户营销记录
原始字段：18 个（人口特征、账户财务、营销触达、历史表现、通话行为等）
目标变量：y（是否订阅定期存款 1/0）
样本分布：正样本约 12%，存在不平衡特性
三、分析框架（4 大模块）
1. 数据处理与特征工程
完成缺失值、异常值、重复值清洗，保证数据质量
对 pdays=-1、余额极端值等做业务化修正
构建 年龄分组、余额分层、贷款组合、历史营销状态、联系方式有效性 等 33 个衍生特征
区分可入模特征（预测用）与事后特征（分析用），避免因果倒置
2. 影响因素与风险识别
多维度 EDA：年龄、职业、余额、贷款、月份、通话时长对转化率的影响
ROI 与边际效益分析：定位最优通话时长区间
逻辑回归（LR）：量化特征影响方向与强度，识别：
正向优质特征：高余额、低负债、历史营销成功、有效联系方式
风险 / 低效特征：高贷款、高频触达、负余额、未知联系方式
3. 预测模型构建与验证
模型选择：逻辑回归、随机森林、XGBoost
模型分工：
LR：因素分析 + 风险因子识别
XGBoost：客户响应预测 + 高潜排序
处理样本不平衡：设置 scale_pos_weight
超参数优化：随机搜索 + 3 折交叉验证
最终指标：F1=0.50，AUC=0.84，PR-AUC=0.53
4. 策略输出与业务落地
客户分层策略：P0~P4 优先级触达体系
营销时机：3/9/10 月为黄金月份
通话策略：4~5 分钟为 ROI 最优通话区间
风控导向建议：高负债、历史失败客户谨慎投放资源
四、核心结论
Top 关键特征：有效联系方式、历史营销成功、高余额、低负债
高价值客群：老年群体、高余额、无贷款、历史转化成功客户
低效 / 风险客群：高贷款、负余额、高频被触达、未知联系方式客户
营销效率提升：可减少约 60% 无效触达，显著提升 ROI
五、技术栈
数据分析：Pandas、NumPy、Matplotlib、Seaborn
统计检验：方差分析、Tukey 检验、Pearson 相关、逻辑回归
机器学习：Scikit-learn、XGBoost、RandomizedSearchCV
评估指标：F1、Recall、Precision、AUC、PR-AUC
